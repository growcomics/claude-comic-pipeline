# BG Beat-Sheet Template — breast + glute (canonical Bloom type)

*Type `bg` per `production-briefing/SKILL.md` — the canonical combined type (BE and glute-only are legacy). Lineup: `breast-glute-size-lineup.png`. House conventions: hourglass maintained; thighs scale with glutes (never dramatically thinner); round symmetric chest shape.*

**Region menu**: `chest`, `hips`, `rear`, `suit_fail`, `whole_body` — the two-front escalation. Order within any multi-region sequence: **breasts first, glutes second** (`posing-and-expressions.md` growth order — softness, then dominance-mass; muscles only if the concept is `mixed`).

**Signature devices**: `multi-panel-progressive` run per front (a chest triptych, then a rear triptych), `clothing-destruction` on two fronts (buttons/neckline forward, seat-seams/waistband rear), `reaction-intercut` (over-the-shoulder looks are the genre's native reaction pose), `size-comparison` (chair, doorway, the rival side-by-side), `sfx-driven`.

**Camera grammar**: chest beats read front/three-quarter; `hips`/`rear` beats read rear three-quarter — plan the turn *into* the pose as panel business (the over-the-shoulder glance back is both a reaction beat and the rear-beat staging).
