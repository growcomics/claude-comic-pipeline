# Style Lock — bottle-game-muscle ("Spin & Swell")

Locked 2026-06-22. Every panel prompt MUST include the prefix and suffix below
verbatim, plus a per-panel CAMERA + LIGHTING line chosen per `references/cinematography.md`.
This project is photorealistic **DAZ3D Studio Iray** 3D rendering on all bodies,
muscles, clothing, props and environment — NOT ink-line, NOT anime, NOT painterly,
NOT cel-shaded. The ONLY 2D element permitted is the flat black-and-white comic
speech bubbles / SFX (L19-baked — see Lettering).

## Model
- Name: Nano Banana 2 / Pro (Flow). Nano Banana Pro for hero/splash panels (the big
  flex reveals p06, p14, p18, p19); Nano Banana 2 for the rest.
- Aspect: 3:4 portrait for solo/close panels; 4:3 / 16:9 wide for the group + establishing
  panels (p01, p11, p19).
- Count: one image per submit; fan out variants by re-running on weak first results.

## Mandatory prompt prefix
> DAZ Studio 4 Iray 3D render, 2021-era Daz3D CGI look, a RENDERED virtual 3D scene (NOT a photograph), 3D Muscle Comics house style, ray-traced Iray subsurface scattering, physically-based Iray materials, soft Iray global illumination, clean slightly-idealized modeled 3D surfaces with a subtle CGI render sheen,

## Mandatory prompt suffix
> the clean rendered look of a Daz Studio Iray scene (like a high-end 3D visual-novel / videogame-cutscene render, NOT a real photo),
> healthy matte rendered skin (not oiled, not wet), cinematic motivated lighting per the panel's lighting note, gentle render bloom, shallow depth of field,
> no painterly softness, no cel shading, no flat front-on flash, no watermarks, no logos.

## Look calibration (IMPORTANT — added 2026-06-22 per feedback)
The target is the recognizable **Daz Studio Iray render** look (circa 2021, Genesis-8-era), NOT AI-photo
realism. It should read as a clean 3D CGI render: soft Iray GI, modeled/staged surfaces, a subtle rendered
sheen — like the studio's existing comics — not like a real photograph. Lead prompts with "DAZ Studio Iray
3D render" and "NOT a photograph"; avoid "hyperrealistic / photographic / 8K photo" which push toward real-photo.

## DAZ3D aesthetic anchor
Bodies, muscles and room read like a rendered DAZ3D Iray scene: real skin SSS, soft global
illumination, modeled (clean, uncluttered) furniture, motivated practical lights. Source one
real DAZ3D-style interior render from the web as the environment look reference, then build a
NEW, simple original living room in Flow off that look — do not copy the source. The background
stays SIMPLE so the women are the focus.

## Muscle arc (FMG — MUSCLE-DOMINANT, 6 tiers per the supplied 1→6 reference chart)
Growth is about MUSCLE, not height. Tiers, matched to the reference chart `references/muscle-tiers-1-6.png`:
1 slim baseline → 2 toned → 3 athletic/fit → 4 clearly muscular (shirt straining) → 5 very muscular
(shirt tearing) → 6 HUGE female bodybuilder (massive defined muscles, clothes ripped open but still
covered). **Build increases DRAMATICALLY; height increases only MODESTLY** — they are NOT giantesses,
NEVER tall-with-little-muscle. A woman only moves UP a tier (monotonic, never shrinks). Muscles are
powerful, defined and SEXY — natural skin tone (NOT red, NOT inflamed, NOT oiled), beautiful feminine
face kept throughout. Clothing tears progressively each tier (sleeve splits → seam rips → shredded)
but she stays covered — no nudity. Across the 20 pages, ramp toward tier 5–6 by the finale.
State each woman's current tier (1–6) every panel and scale her against the FIXED-SIZE furniture.

## Scale rule (continuity-critical — added 2026-06-22 per feedback)
The ENVIRONMENT stays a FIXED real-world size in every panel — couch, coffee table, bookshelf,
rug, bottle, snacks, lamp, window: all constant. ONLY the women grow. As each woman gains muscle
she grows TALLER and BIGGER, so she looks visibly larger against the unchanged furniture (by the
finale she dwarfs the couch). Never shrink/enlarge the furniture to "fit" a woman — keep props
constant and use the couch/rug as the size yardstick so the growth reads clearly. State each
woman's current tier in every panel; growth is monotonic (never shrinks back).

## Continuity (per panel — see references/continuity.md)
Winner-first chaining: attach the PREVIOUS approved panel + the cast sheet + room ref + the
BOTTLE ref on every panel. Keep set dressing (snacks, bowls, cans) in the SAME places; keep each
woman in the SAME seat unless she moves; on a camera move attach a full-room ref so geometry stays
honest. The BOTTLE always matches its dedicated ref; when the spin stops it lies ON ITS SIDE
pointing at the chosen woman (never upright). Only change what the beat changes.

## Cinematography (per panel — see references/cinematography.md)
- Vary shot size + angle every panel. Power/flex beats: LOW angle + hard rim/back light carving
  the muscle, low fill, dramatic. The spinning bottle / the circle of players: TOP-DOWN angle.
  Nervous / "it landed on me" beats: slightly HIGH angle or dutch tilt. Group/cozy beats: bounce
  light, high-key, warm. ALWAYS name a key + a rim + a practical/motivated source.

## Lettering — L19-baked, classic black & white comic
Speech bubbles and SFX are flat 2D black-and-white comic graphics composited on the photoreal CGI:
white balloon, bold solid black outline, ALL-CAPS bold Bangers-style font, triangular tail to the
named speaker. SFX (WHIRRR / FFLEX / RRRIP / KRAKOOM) as bold black-outline comic lettering. The
2D styling applies ONLY to bubbles/SFX — everything else stays photoreal DAZ3D CGI.
