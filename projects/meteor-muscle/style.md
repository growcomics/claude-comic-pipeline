# Style Lock — meteor-muscle ("Critical Mass")

Locked 2026-06-23. Every panel prompt MUST include the prefix and suffix below verbatim.
Photorealistic DAZ3D 3D rendering on all bodies, clothing, props and environment — NOT ink-line,
NOT anime, NOT painterly. The ONLY 2D element permitted is the flat black-and-white comic speech
bubbles / captions / SFX (L19-baked).

## Model
- Nano Banana 2 (Flow) for panels. Nano Banana Pro for the reference/turnaround sheets and the p14 splash money-shot (spend Pro's daily quota on refs + hero shots).
- Aspect: 16:9 for wide/establishing/sky/splash scale shots; 4:3 for medium/two-shots; 1:1 for ECU faces; 3:4 for full standing figures. Vary per panel (see shotlist `view`).
- x4 count per Flow submit (4 candidates; pick best).

## Mandatory prompt prefix
> Hyperrealistic DAZ3D Studio Iray 3D CGI render, ray-traced subsurface scattering on skin, physically-based rendering, 8K texture detail, photographic CGI, clean prosumer 3D CGI comic art, 3D Muscle Comics house style,

## Mandatory prompt suffix
> photorealistic skin micro-detail with visible pores and freckles, cinematic golden-hour key light with soft long shadows plus a cool rim light, gentle bloom, shallow depth of field, well-lit Iray global illumination;
> sharp focus, crisp cloth and material detail. Not glossy cinematic VFX, no painterly softness, no cel shading, no watermarks, no logos.

## Mandatory negative prompt
> cartoon body, anime, 2D illustration of the figures, painting, watercolor, ink-line characters, cel-shaded skin, plastic skin, oversmoothed, flat front-on flash lighting, watermark, logo, deformed hands, extra limbs, child, teen, underage, fat/obese (this is MUSCLE not fat), red inflamed skin.

## Aesthetic anchor — DAZ3D + cinematic
Bodies and campus read like a rendered DAZ3D Iray scene: real skin SSS + freckles, soft GI, modeled
stone architecture, realistic foliage. Cinematic golden-hour lighting (warm key + cool rim, long
shadows, haze) — matches the lighting bar of the reference comic. Source a DAZ3D university set
(FG University / University Lecture Hall) for the look; build a NEW original Ashgrove courtyard in
Flow off it; use DIFFERENT SUB-AREAS per panel, never the identical framing twice.

## Transformation — FMG MUSCLE (size lineup control)
Female muscle growth ONLY. Hazel goes muscle size 1 -> 6 across the arc (see shotlist tiers).
- **Use the numbered muscle-size lineup image** (sizes 1-6) as a visual anchor on every stage-change
  panel (p08 size2, p09 size3, p11 size4, p12/p13 size5, p14 size6). Call out the size NUMBER in the
  prompt: "Hazel's muscle/breast/waist proportions match size N in the muscle-size lineup reference."

  lightly oiled skin catching warm light (rule 2), NOT wet/painful.
- Per rule 3, the enlarged-muscle figure also has proportionally enlarged full breasts with cleavage,
  coverage preserved (L4).
- Monotonic: once at a size, never smaller (rule 10).
- It is MUSCLE, never fat. Hourglass-athletic, deep muscle separation and vascularity at high tiers.

## Scale constancy (L37)
Brooke, Tiffany and the entire campus are a FIXED normal size in EVERY panel — scale them to the stone
steps / benches / doorways / the bullies themselves. ONLY Hazel changes. The non-transforming
characters must never look bigger or smaller between panels.

## Lettering — L19 BAKED
Speech bubbles / captions / SFX baked into each render at generation time.
- Bubbles: classic black-and-white 2D comic balloons — clean WHITE rounded ovals, bold 3-4px solid
  BLACK outline, ALL-CAPS bold black comic display font (Bangers-style), short triangular
  black-outlined tail to the correct speaker's mouth.
- Captions: yellow (or white) rounded rectangle, bold black outline, comic font, top or bottom edge.
- SFX: flat 2D bold black/white ALL-CAPS comic display lettering, solid black outline — NOT 3D extruded.
- Flat 2D overlay ONLY: no 3D shading/bevel/translucency on the lettering, no drop shadow onto the scene.
- Scope line (append to every lettered prompt): photoreal DAZ3D CGI on bodies, skin, clothing, campus
  and lighting; ONLY the bubble / caption / SFX graphics are flat 2D black-and-white comic overlay.

## Banned
- Ink outlines / cel shading / anime / painterly rendering on figures or campus.
- Fat instead of muscle; red/inflamed muscle skin.
- Hazel shrinking below a previously reached muscle size; bullies/campus changing scale.
- Nudity — torn clothing always covers chest/groin (L4).
- Characters making eye contact with the camera in narrative panels (they look at each other / their target).
